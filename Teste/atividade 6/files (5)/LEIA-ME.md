# Lista de Tarefas (back-end + front-end)

## Como rodar
1. Instale o Node.js: https://nodejs.org
2. Na pasta do projeto: `npm install`
3. Inicie: `npm start`
4. Abra http://localhost:3000

## Estrutura
- server.js        -> BACK-END (API + dados)
- public/index.html -> FRONT-END (estrutura)
- public/style.css  -> FRONT-END (aparência)
- public/script.js  -> FRONT-END (comportamento)
