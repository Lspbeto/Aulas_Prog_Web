O que é a Tag <nav>?

A tag <nav> é um elemento semântico do HTML5 projetado especificamente para agrupar blocos de links de navegação. Seja para o menu principal do site, um sumário, índices ou links de paginação, ela indica que o conteúdo ali dentro tem a função de guiar o usuário.

Principais Características

  • Foco em Links Importantes: Não deve ser usada para agrupar qualquer lista de links genéricos (como rodapés com dezenas de links de parceiros); serve prioritariamente para a navegação principal.
  • Acessibilidade (Screen Readers): Tecnologias assistivas usam a tag <nav> para permitir que usuários com deficiência visual pulem direto para os menus de navegação sem precisar ouvir o site inteiro.
  • Uso com atributos ARIA: Quando há mais de um elemento <nav> na página, é altamente recomendado usar o atributo aria-label para diferenciá-los (ex: aria-label="Menu Principal").
  • Flexibilidade de Posicionamento: Pode aparecer dentro de um <header>, sozinha no corpo da página, ou até mesmo dentro de um rodapé (<footer>).

Exemplo de Código

Veja abaixo a estrutura padrão recomendada para uma barra de navegação:

<nav aria-label="Navegação Principal">
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="produtos.html">Produtos</a></li>
        <li><a href="contato.html">Contato</a></li>
    </ul>
</nav>
