O que é a Tag <header>?

A tag <header> é um elemento semântico introduzido no HTML5. Ela é utilizada para representar um grupo de conteúdos introdutórios ou de navegação, geralmente posicionada no topo de uma página ou de uma seção específica.

Principais Características

  • Não é restrita ao topo do site: Embora seja comum usá-la no início da página inteira, você pode colocar um <header> dentro de artigos (<article>) ou seções (<section>).
  • Conteúdo típico: Costuma abrigar logotipos, títulos principais (<h1> a <h6>), menus de navegação (<nav>), formulários de busca ou dados de autoria.
  • Múltiplos usos: Uma página web pode conter vários elementos <header>, desde que cada um pertença a contextos diferentes.
  • Acessibilidade e SEO: Ajuda leitores de tela e robôs de busca (como o Google) a entenderem rapidamente a estrutura hierárquica do conteúdo.

Exemplo de Código

Veja abaixo como estruturar um cabeçalho básico utilizando HTML semântico:

<header>
    <img src="logo.png" alt="Logotipo da Empresa">
    <nav>
        <ul>
            <li><a href="#">Início</a></li>
            <li><a href="#">Sobre</a></li>
            <li><a href="#">Contato</a></li>
        </ul>
    </nav>
</header>
