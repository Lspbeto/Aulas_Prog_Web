O que é a Tag <main>?

A tag <main> é um elemento semântico do HTML5 que especifica o conteúdo principal do corpo de um documento. Ela deve conter o conteúdo que é central para o tópico da página ou que expande diretamente a funcionalidade central dela.

Principais Características

  • Conteúdo Único: Deve haver apenas um elemento <main> visível por página. Ele não deve conter conteúdo que se repete em várias páginas (como menus de navegação globais, logotipos ou rodapés).
  • Exclusão de Elementos Globais: Itens como barras laterais de links (sidebar), formulários de busca recorrentes ou cabeçalhos principais do site geralmente ficam fora do <main>.
  • Impacto em Acessibilidade: Auxilia leitores de tela a localizarem rapidamente o miolo informativo do site, permitindo que o usuário ignore seções repetitivas.
  • Regras de Aninhamento: Não pode ser descendente de elementos como <article>, <aside>, <footer>, <header> ou <nav>.

Exemplo de Código

Veja como o elemento se integra na estrutura de uma página web comum:

<body>
    <header>
        <h1>Meu Blog</h1>
        <nav>...</nav>
    </header>

    <main>
        <article>
            <h2>Entendendo o HTML Semântico</h2>
            <p>O uso correto de tags melhora o SEO e a acessibilidade...</p>
        </article>
    </main>

    <footer>
        <p>&copy; 2026 Meu Blog</p>
    </footer>
</body>
